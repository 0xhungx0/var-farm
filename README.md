# VAR Farm

Live, read-only funding-rate scanner for markets shared by Variational Omni and Hyperliquid.

The page compares annualized funding, recommends the lower-cost long/short orientation, checks the cross-venue mark-price gap, and estimates gross daily carry for a chosen position size.

Research tool only. Estimates exclude spread, slippage, liquidation risk, contract differences, and future funding-rate changes.
